# Turan Text Corrector — демо

**Сайт:** https://correctecor.kz

Исправление орфографии казахского текста. Нейросеть KazRoBERTa находит слова с
ошибками, корректор подбирает правильную форму: сначала замены русских букв на
казахские (а→ә, к→қ, н→ң …) и пары гармонии гласных, затем ближайшее слово из
словаря (~174 тыс. словоформ). Можно вставить текст или загрузить файл
(.txt, .docx, .pdf … до 5 МБ). Русский текст распознаётся, но не исправляется.

## Результаты модели

KazRoBERTa (`kz-transformers/kaz-roberta-conversational`, 6 слоёв, ~83 млн
параметров), дообучена искать ошибки (метка KEEP / ERROR для каждого слова) на
2,57 млн пар предложений с синтетическими ошибками, 2 эпохи. Тест — 8 000
предложений, которых не было в обучении.

| Метрика | Значение |
|---|---|
| Поиск ошибок: точность / полнота / F1 | 97,1% / 97,4% / **97,3%** |
| Ложные срабатывания на правильных словах | 0,34% |
| Предложений исправлено целиком (детектор + корректор) | **81,2%** |
| То же при идеальном детекторе (потолок корректора) | 83,8% |
| Весь текст на русской раскладке: найдено ошибок / исправлено предложений | 70,0% / 54,9% |

Ошибки в тесте синтетические и того же вида, что в обучении (казахские буквы
заменены русскими, нарушена гармония гласных, перестановки, пропуски, повторы и
замены букв; не больше трёх ошибок на предложение). На реальных текстах цифры
могут быть ниже. Слабое место — текст, целиком набранный без казахских букв.

## Как устроено

| Часть | Где | Что |
|---|---|---|
| Страница | GitHub Pages, этот репозиторий, домен `correctecor.kz` (DNS в Plesk на ps.kz) | собранный React-фронтенд |
| Сервер | [Hugging Face Space `daniyar51/turan-text-corrector`](https://huggingface.co/spaces/daniyar51/turan-text-corrector) | FastAPI + PyTorch (CPU) в Docker: принимает текст со страницы, прогоняет через модель и корректор, возвращает исправленный текст |
| Модель | [Hugging Face `daniyar51/kazroberta-kazakh-spelling-detector`](https://huggingface.co/daniyar51/kazroberta-kazakh-spelling-detector) | обученный детектор KazRoBERTa и словарь корректора; Space скачивает их при сборке (зафиксированная версия) |

Сервер засыпает, если сайтом долго не пользуются; первый запрос после сна идёт
около минуты, страница показывает «Сервер просыпается…». Action
`keep-awake.yml` раз в 6 часов будит сервер, чтобы он не уснул надолго.

API сервера: `https://daniyar51-turan-text-corrector.hf.space/docs`

## Обновление

Исходный код — [daniyar3348/text_corrector](https://github.com/daniyar3348/text_corrector).

```bash
# модель: веса, токенизатор, словарь и описание → репозиторий модели;
# напечатанный MODEL_REVISION вписать в text_corrector/backend/space/Dockerfile
python text_corrector/backend/scripts/publish_model.py

# сервер (Space): только код из text_corrector/backend, модель он скачает сам
python text_corrector/backend/scripts/deploy_space.py

# страница: сборка в эту папку, затем commit + push
bash text_corrector/frontend/scripts/build_pages.sh ~/Desktop/Projects/turan-demo
```

Цифры в блоке «Результаты модели» — `backend/scripts/eval_end2end.py model 8000`
и `backend/scripts/eval_stress.py`.
